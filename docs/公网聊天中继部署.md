# 公网聊天中继部署

公网聊天室由一个 Go 程序支撑：把它编译好丢到服务器上运行，再用 Caddy 或 Nginx 反代成 HTTPS 即可。客户端不内置服务器地址，部署完成后把地址发给使用者。

> 下文里的 `chat.example.com` 只是示例，请全部换成你自己的域名（需提前解析到这台服务器）。

## 一、编译

需要 Go 1.26 或更高版本。

```bash
cd relay

# Linux x64
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -trimpath -ldflags "-s -w" -o xlan_relay_linux_amd64 .

# Windows x64
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 \
  go build -trimpath -ldflags "-s -w" -o xlan_relay_windows_amd64.exe .
```

数据库用纯 Go 的 SQLite，不需要 CGO 环境。

## 二、启动

把二进制传到服务器，直接运行：

```bash
./xlan_relay_linux_amd64 -addr 127.0.0.1:43500 -public-url https://你的域名
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-addr` | `127.0.0.1:43500` | 监听地址，用反代时保持只监听本机 |
| `-data` | `xlan_server_data` | 数据目录，不填就在运行目录下自动生成，一般不用管 |
| `-public-url` | 空 | 对外域名，例如 `https://chat.example.com` |
| `-key` | 自动生成 | 地址里的路径密钥，不填自动生成并保存到 `xlan_server_data/key` |
| `-max-file-mb` | `10` | 单个文件大小上限（MB） |

启动日志会打印访问地址，例如：

```
访问地址：https://chat.example.com/xlan/AbCdEfGh1234567890ab
```

这就是客户端要填的中继地址。升级时替换二进制、重启服务即可，`xlan_server_data/` 不动，历史数据不会丢。

## 三、反向代理

对外只开放 80/443，`43500` 不要暴露到公网。反代需要支持 WebSocket 升级，请求体上限调到不小于 `-max-file-mb`。

### Caddy（推荐，自动证书）

```caddyfile
chat.example.com {
    reverse_proxy 127.0.0.1:43500
}
```

### Nginx

```nginx
server {
    listen 443 ssl;
    server_name chat.example.com;

    ssl_certificate     /etc/letsencrypt/live/chat.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/chat.example.com/privkey.pem;

    client_max_body_size 25m;

    location /xlan/ {
        proxy_pass http://127.0.0.1:43500;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

## 四、宝塔面板部署

宝塔 9 以上自带 Go 项目管理器，不用装 PHP、也不用自己写 Nginx 配置：

1. **上传程序**：文件 → 进入 `/www/wwwroot/xlan-relay/`，上传 `xlan_relay_linux_amd64`，右键「权限」设为 755。
2. **添加项目**：网站 → Go项目 → 添加Go项目：
   - 项目名称：`xlan-relay`
   - 项目路径：`/www/wwwroot/xlan-relay`
   - 执行文件：`xlan_relay_linux_amd64`
   - 项目端口：`43500`
   - 绑定域名：`chat.example.com`（域名填这里，宝塔会自动配好反向代理和 WebSocket 升级）
   - 启动参数：`-addr 127.0.0.1:43500 -public-url https://你的域名`（数据目录默认生成在项目目录下，不用填）
   - 勾选「自动重启」和「开机自启」
3. **证书**：站点设置 → SSL → Let's Encrypt 申请，然后开启「强制 HTTPS」。

启动后到项目的日志里看打印的访问地址，就是客户端要填的中继地址。如果调大了 `-max-file-mb`，在站点设置 → 配置文件里把 `client_max_body_size` 改到不小于它。

## 五、开机自启（Linux）

```ini
[Unit]
Description=X互传 公网聊天中继
After=network.target

[Service]
WorkingDirectory=/srv/xlan-relay
ExecStart=/srv/xlan-relay/xlan_relay_linux_amd64 -addr 127.0.0.1:43500 -public-url https://你的域名
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now xlan-relay
```

## 六、客户端填写

Windows 与 Android 都在「设置 → 公网聊天室 → 服务器地址」里填写日志打印的完整地址：

```
https://chat.example.com/xlan/AbCdEfGh1234567890ab
```

不写协议时按 `https://` 补全；留空即关闭公网聊天室。

## 排障

- 客户端一直「未连接」：确认反代放通了 `/xlan/` 路径、证书有效、WebSocket 能升级。
- 上传大文件失败：把 `client_max_body_size`（或 Caddy 的 `request_body.max_size`）调大。
- 日志里地址不对：检查 `-public-url` 是否带 `https://`、末尾不要加 `/`。
- 想换地址：改 `-key` 或删掉 `xlan_server_data/key` 重新生成，之后客户端同步改。
